# Week 1 - QA Mindset and Manual Testing Fundamentals

## Objective

The goal of Week 1 was to build a basic understanding of software testing and develop a QA mindset.

## Application Tested

For practical testing, I used SauceDemo.

## Modules Covered

- Login
- Products
- Shopping Cart
- Checkout

## Topics Learned

- Software Testing Fundamentals
- Manual Testing
- Automation Testing
- Functional Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- Positive Testing
- Negative Testing
- UI Testing
- Usability Testing
- Compatibility Testing
- Exploratory Testing
- Test Scenario vs Test Case
- Bug Reporting
- Severity vs Priority
- Risk-based Testing
- Edge Cases

## Practical Work Completed

- Identified application modules
- Identified user roles and risky areas
- Created test scenarios
- Created test cases
- Practiced positive and negative testing
- Created a reusable bug report template
- Identified and documented bugs
- Collected screenshots as testing evidence

## Deliverables

- Application module analysis
- Test scenarios
- Test cases
- QA fundamentals notes
- Bug report template
- Daily learning logs
- Testing evidence

## Key Learning

Week 1 helped me understand how a QA tester thinks about software quality, risks, expected behavior, unexpected behavior, and defects.
