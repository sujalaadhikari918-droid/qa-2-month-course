## Month 1 Work Done (Week-wise)

### Week 1: QA Mindset and Manual Testing Fundamentals

- Chose the SauseDemo app and explored it as a normal user.
- Identified the main modules, user roles and risky areas.
- Listed 10+ modules/features of the app.
- Wrote 20 possible test scenarios.
- Created a reusable bug report template.
- Kept a daily learning log (5 days).

### Week 2: Requirement Analysis and Test Case Writing

- Picked modules from SauceDemo to focus on.
- Did requirement analysis.
- Wrote 30 high-level test scenarios.
- Converted the scenarios into 40 detailed test cases.
- Prepared a test data list with valid and invalid sample data.
- Reviewed the steps to check that another tester could follow them without confusion.
- Prepared a small traceability matrix mapping requirements to test cases.
- Wrote a weekly log with learnings and blockers.

### Week 3: Functional, Smoke, Sanity, Regression and Negative Testing

- Created a smoke checklist of 10-15 critical checks.
- Executed 40 functional test cases.
- Did regression testing for the major modules.
- Wrote 17 negative test cases and tested forms with invalid, empty, long, duplicate and special-character input.

### Week 4: UI/UX, Compatibility, Accessibility Basics and DevTools Evidence

- Tested OrangeHRM in 2 browsers: [Chrome and Edge].
- Resized the browser to mobile, tablet and desktop widths and took screenshots.
- Checked spelling, alignment, loading states and broken layouts.
- Created a UI checklist with 30+ checks.
