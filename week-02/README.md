
# Week 2 - Requirement Analysis and Test Case Writing

## Objective

The goal of Week 2 was to learn how to understand requirements and convert them into test scenarios, detailed test cases, test data, and traceable test coverage.

## Application Used

For practical work, I continued using SauceDemo.

## Modules Covered

- Login
- Products
- Shopping Cart
- Checkout

## Topics Learned

- Understanding Requirements
- Requirement Analysis
- Expected Behavior
- Negative Requirements
- Risk Identification
- Acceptance Criteria
- Requirement Ambiguity
- Testable Conditions
- Positive Testing
- Negative Testing
- Boundary Testing
- Empty State Testing
- Error State Testing
- Test Data
- Test Scenarios
- Test Cases
- Traceability

## Practical Work Completed

- Analyzed requirements for selected modules
- Created high-level test scenarios
- Converted scenarios into detailed test cases
- Created valid and invalid test data
- Created a simple traceability matrix
- Mapped requirements to test cases
- Reviewed test cases for clarity

## Deliverables

- Requirement analysis
- 30 test scenarios
- 40 detailed test cases
- Test data list
- Traceability matrix
- Daily learning logs

## Key Learning

Week 2 helped me understand how requirements are converted into testable conditions and how test scenarios and test cases can be connected back to the requirements through traceability.
